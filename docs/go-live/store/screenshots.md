# Screenshots

What each store needs, and what each picture shows. Pictures come from the app running on the simulators with the demo business's sample data (never a real customer's), taken with `tools/listing-shots`. They are labelled as examples. No picture shows a price promise, a ranking claim, or any text naming Meta as an approver.

Sizes: Google Play, phone: 2 to 8 screenshots, 16:9 or 9:16, each side 320 to 3840 px, plus a 512x512 icon and a 1024x500 feature graphic. App Store, iPhone 6.9 inch: 1 to 10 screenshots, for example 1320x2868; an iPad set only if the app supports iPad (it does not).

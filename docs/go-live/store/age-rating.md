# Age rating answers

Answers for the Google Play (IARC) and App Store questionnaires. They follow what the apps do, not what a business sells; a business that sells age-restricted goods answers for its own app.

| Question | Bhava for Business | A seller's branded app |
| --- | --- | --- |
| Violence, fear or horror | None | None |
| Sexual content or nudity | None | None |
| Profanity or crude humour | None | None |
| Drugs, alcohol or tobacco content | None | None, unless the business sells them (then it answers for its own app) |
| Gambling or simulated gambling | None | None |
| User-generated content shared with other users | None. Messages go to the business's own customers | Product reviews with photos, moderated by the business |
| Users can talk to each other | No | No |
| Shares location | No | No |
| Unrestricted web access | No | No |
| Purchases in the app | No. The apps sell no digital goods | Physical goods, paid through the payment gateway |
| Collects personal information | Yes: see play-data-safety.md | Yes: see branded-app.md |

Expected result: Everyone (Play) and 4+ (App Store) for both. The App Store's "Made for kids" and Play's "Designed for families" are not selected.
